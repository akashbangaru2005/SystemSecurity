# SecureCore - System Security Simulation

A browser-based interactive security simulation built with Flask, HTML, CSS and JavaScript.

## Features

- Responsive mobile UI
- iPhone and Android support
- Tablet support
- Desktop support
- Animated security diagnostics
- Simulated network analysis
- Simulated visual sensor
- Simulated location analysis
- Simulated biometric verification
- Sound effects
- Vibration support where available
- Fullscreen support
- Final prank reveal

## Installation

Create a virtual environment:

python -m venv venv

Activate:

Windows:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Run:

python app.py

Open:

http://127.0.0.1:5000

## Important

This is a harmless browser simulation.

It does not access:

- Camera
- Microphone
- GPS
- Fingerprint sensor
- Device files
- Private data
